# Journal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local journal app (work issue cards + ranked wishlist) that runs in the browser and saves to `data/journal.json`.

**Architecture:** `store.py` owns the data file (load, versioned save, atomic write, daily backups). `server.py` is a stdlib HTTP server on `127.0.0.1:8765` that serves `web/` and exposes `GET/PUT /api/data`. The browser app is plain ES modules with no build step; one in-memory `state` object is rendered by the Work and Wishlist modules and autosaved by `save.js`.

**Tech Stack:** Python 3.13 standard library only (`http.server`, `json`, `unittest`). Plain HTML/CSS/JavaScript (ES modules), no frameworks, no Node.

**Spec:** `docs/superpowers/specs/2026-11-03-journal-design.md`

## Global Constraints

- No third-party Python packages, no Node, no JS frameworks, no build step.
- Server binds `127.0.0.1` only, port `8765`.
- Data file `data/journal.json`; backups in `data/backups/journal-YYYY-MM-DD.json`; keep newest 14.
- Damaged file renamed to `data/journal.broken-YYYY-MM-DD-HHMMSS.json`; never deleted.
- Data shape exactly as spec §3 (`version`, `issues[]`, `wishlist[]`; wishlist rank = array order, index 0 highest).
- Prices in rand, displayed `R 1 299.00` (space as thousands separator, 2 decimals); unknown price is `null` and shows nothing.
- Autosave ~1 s after last edit (debounce 1000 ms); retry every 10 s while offline.
- Exact UI copy: `Not saved — start Journal.bat`; `This journal was changed in another tab. Reload to continue.`; `Your journal file was damaged and set aside. Restore a copy from data\backups.`; status `Saved` / `Saving…`.
- All files read and written as UTF-8. Timestamps are local time, `YYYY-MM-DDTHH:MM:SS`; dates `YYYY-MM-DD`.
- `.js` files must be served as `text/javascript` (Windows registry can map `.js` to `text/plain`, which breaks modules) — set it explicitly in the handler.

## Review Focus

1. **Path traversal in static serving** — `GET /../data/journal.json` (or `%2e%2e` encoded) must return 404, not the data file. Test in Task 2.
2. **Malformed PUT body** — non-JSON or wrong shape (e.g. `issues` not a list) must return 400 and leave the file unchanged. Tests in Tasks 1 and 2.
3. **Non-ASCII text** — `é`, `ñ`, emoji in titles/notes must round-trip unchanged. Test in Task 1.
4. **Price typed loosely** — `1299`, `1 299`, `R1,299.50`, `R 1 299.00` all parse; `abc` or empty becomes `null`. Test in Task 3 (`format-test.html`).
5. **Unsafe or bare links** — `shop.co.za/x` gets `https://` prefixed; `javascript:alert(1)` is rejected (no link rendered). Test in Task 3 (`format-test.html`).

### Task 1: Data store (`store.py`)

**Files:**
- Create: `store.py`, `tests/__init__.py` (empty)
- Test: `tests/test_store.py`

**Interfaces:**
- Produces:
  - `class ConflictError(Exception)` — raised when a save's `version` is stale.
  - `class JournalStore(data_dir: Path, now: Callable[[], datetime] = datetime.now)`
  - `JournalStore.load() -> dict` — returns `{"version": int, "issues": list, "wishlist": list, "damaged": bool}`. Missing file → creates empty journal at version 0. Invalid JSON → renames file to `journal.broken-<YYYY-MM-DD-HHMMSS>.json`, starts empty, sets `damaged` True until the next successful save.
  - `JournalStore.save(data: dict) -> int` — raises `ValueError` if `data` lacks int `version`, list `issues`, list `wishlist`; raises `ConflictError` if `data["version"]` != current version; otherwise writes `{version: current+1, issues, wishlist}` (drops any other keys, e.g. `damaged`) and returns the new version.

  - `test_load_missing_creates_empty`: `load()` == `{"version":0,"issues":[],"wishlist":[],"damaged":False}`; `journal.json` exists.
  - `test_save_then_load_roundtrip`: save `{"version":0,"issues":[{"id":"a","title":"x"}],"wishlist":[]}` returns 1; `load()["issues"][0]["title"] == "x"`, `version == 1`.
  - `test_stale_version_raises_conflict`: after one save, saving with `version: 0` raises `ConflictError`; file still at version 1.
  - `test_bad_shape_raises_value_error`: `save({"version":0,"issues":"no","wishlist":[]})` raises `ValueError`; file unchanged.
  - `test_unicode_roundtrip`: title `"Café ñ 🎮"` survives save+load; raw file bytes decode as UTF-8 and contain `Café` (use `ensure_ascii=False`).
  - `test_damaged_file_set_aside`: write `{not json` to `journal.json`, `now` = 2026-11-03 14:05:09; `load()` returns empty with `damaged True`; `journal.broken-2026-11-03-140509.json` exists with original bytes; after a successful save, `load()["damaged"]` is False.

### Task 2: HTTP server and launcher

**Files:**
- Create: `server.py`, `Journal.bat`, `web/index.html` (placeholder `<h1>Journal</h1>`, replaced in Task 3)
- Test: `tests/test_server.py`

**Interfaces:**
- Consumes: `JournalStore`, `ConflictError` from Task 1.
- Produces:
  - `make_server(data_dir: Path, web_dir: Path, port: int) -> ThreadingHTTPServer` bound to `127.0.0.1`.
  - `GET /api/data` → 200, JSON from `JournalStore.load()`.
  - `PUT /api/data` (JSON body) → 200 `{"version": <new>}`; 409 `{"error": "conflict"}`; 400 `{"error": "bad request"}` for invalid JSON or `ValueError`.
  - Static: `GET /` → `web/index.html`; other paths served from `web/`; anything resolving outside `web/` → 404.
  - All JSON responses `Content-Type: application/json; charset=utf-8`, `Cache-Control: no-store`.
  - `main()` — `make_server(ROOT/"data", ROOT/"web", 8765).serve_forever()`; if binding fails with `OSError` (port in use), print `Journal is already running.` and exit 0.

- [ ] **Step 1: Write the failing tests** in `tests/test_server.py`: `setUp` starts `make_server(tmp/"data", tmp/"web", 0)` in a thread (port 0 = free port; read `server.server_address[1]`), with `tmp/"web"/"index.html"` = `<h1>hi</h1>` and `tmp/"web"/"a.js"` = `x`; `tearDown` shuts it down. Use `http.client`.
  - `test_get_data_empty`: GET `/api/data` → 200, body `version == 0`.
  - `test_put_then_get`: PUT version 0 with one issue → 200 `{"version":1}`; GET shows the issue.
  - `test_put_stale_409`: second PUT with `version: 0` → 409, body `{"error":"conflict"}`.
  - `test_put_invalid_json_400`: PUT body `not json` → 400; GET still `version == 0`.
  - `test_put_bad_shape_400`: PUT `{"version":0,"issues":5,"wishlist":[]}` → 400.
  - `test_index_served`: GET `/` → 200, body contains `<h1>hi</h1>`.
  - `test_js_content_type`: GET `/a.js` → `Content-Type` starts with `text/javascript`.
  - `test_path_traversal_404`: GET `/../data/journal.json` and `/%2e%2e/data/journal.json` → 404.

- [ ] **Step 2: Run tests, expect failure**
  Run: `python -m unittest tests.test_server -v`
  Expected: `ModuleNotFoundError: No module named 'server'`.

- [ ] **Step 3: Implement `server.py`.** Subclass `SimpleHTTPRequestHandler` with `directory=web_dir` (via `functools.partial`), set `extensions_map[".js"] = "text/javascript"`, handle `/api/data` in `do_GET`/`do_PUT`, and reject any path whose resolved file is not inside `web_dir` with 404. Silence request logging (`log_message` no-op).

- [ ] **Step 4: Write `Journal.bat`:**

### Task 3: App shell, formatting helpers and autosave

**Files:**
- Create: `web/index.html` (replace placeholder), `web/style.css`, `web/app.js`, `web/save.js`, `web/format.js`, `web/test/format-test.html`
- Create stubs: `web/work.js`, `web/wishlist.js` (each exports its render function rendering a heading only; filled in Tasks 4–5)

**Interfaces:**
- Consumes: `GET/PUT /api/data` from Task 2.
- Produces:
  - `format.js`:
    - `formatRand(n: number|null) -> string` — `1299` → `"R 1 299.00"`, `0` → `"R 0.00"`, `null` → `""`.
    - `parsePrice(s: string) -> number|null` — strips `R`, spaces and commas; `"R1,299.50"` → `1299.5`; `""`/`"abc"` → `null`.
    - `safeLink(s: string) -> string|null` — trims; empty → `null`; no scheme → prefix `https://`; only `http:`/`https:` allowed, else `null`.
    - `todayISO() -> "YYYY-MM-DD"` and `nowISO() -> "YYYY-MM-DDTHH:MM:SS"` (local time).
    - `newId() -> string` — `crypto.randomUUID()`.
  - `save.js`: `createSaver({ getData: () => object, onStatus: (status: "saved"|"saving"|"offline"|"conflict", version?: number) => void }) -> { changed(): void }`. `changed()` debounces 1000 ms then PUTs `getData()`; on 200 sets the state's version via `onStatus("saved", version)`; on network error → `"offline"` and retries every 10 000 ms until success; on 409 → `"conflict"` and stops all further saves. Registers `beforeunload` that prompts while a save is pending or failed.
  - `app.js`: holds `state = {version, issues, wishlist}`; loads `/api/data` on start; shows the damaged notice if `damaged`; renders two tabs (Work default, Wishlist) and calls `renderWork(root, state, changed)` / `renderWishlist(root, state, changed)`; status line shows `Saved` / `Saving…`; red bar shows the exact offline or conflict copy from Global Constraints. If the initial load fails, show the offline red bar.
  - `work.js` exports `renderWork(root: HTMLElement, state, changed: () => void)`; `wishlist.js` exports `renderWishlist(root: HTMLElement, state, changed: () => void)`. Render functions mutate `state` in place and call `changed()` after each edit.

- [ ] **Step 1: Write the failing browser test** `web/test/format-test.html`: a module script importing `../format.js` that runs these assertions and writes `All 13 passed` or each failure into the page:
  - `formatRand(1299) === "R 1 299.00"`, `formatRand(1234567.5) === "R 1 234 567.50"`, `formatRand(0) === "R 0.00"`, `formatRand(null) === ""`
  - `parsePrice("1299") === 1299`, `parsePrice("1 299") === 1299`, `parsePrice("R1,299.50") === 1299.5`, `parsePrice("R 1 299.00") === 1299`, `parsePrice("abc") === null`, `parsePrice("") === null`
  - `safeLink("shop.co.za/x") === "https://shop.co.za/x"`, `safeLink("javascript:alert(1)") === null`, `safeLink("") === null`

- [ ] **Step 2: Run it, expect failure** — with the server running, open `http://localhost:8765/test/format-test.html`. Expected: page shows a module load error / failures (format.js missing).
